# 브랜드 셀프 오리엔시트 (마이그레이션 186~195·200)

> 브랜드가 로그인 없이 토큰 링크로 오리엔시트를 한국어로 작성·제출 → 관리자가 자동 채움으로 캠페인 발행. 사양서 `docs/specs/2026-06-18-brand-self-orient-sheet.md`(§15 형식 재설계). 이후 조각은 항목마다 배포 상태를 따로 적는다.
- 익명 함수 3종 (GRANT anon, SECURITY DEFINER + `search_path=''`, 토큰 미매칭/만료/consumed 차단, 140·187 패턴): `get_orient_sheet(token)`(조회 + `initial_values` 승계) · `save_orient_draft(token, data, version)`(낙관적 락·100KB·status 미변경) · `submit_orient_sheet(token, data, version)`(재제출 허용). data jsonb 투명 전달. **`set_orient_form_type`은 마이그194에서 DROP**. `create_orient_sheet(brand_id, application_id)`는 마이그195로 2인자(form_type=NULL·빈 cards·brand prefill)
- **카드 고유 번호 `data.cards[].uid`**(마이그레이션 293·294): 카드별 메모를 **순번이 아니라 고유 번호로** 붙이기 위한 값. 🔴 **번호를 만드는 곳은 저장 함수 한 곳뿐**이고 폼은 실어 나르기만 한다(만드는 곳이 둘이면 안전망 발동이 갈려 검증 불가). `_orient_apply_card_uids(들어온data, 저장된data)` 가 `save_orient_draft`·`submit_orient_sheet` 직전에 ⓪정리(문자열 아님·빈값·공백 → 없음, 중복은 처음 것만) ①있으면 유지 ②없고 **「들어온 카드 수 = 저장된 카드 수」일 때만** 같은 자리 번호 물려받기 ③그래도 비면 새 번호. 🔴 **②의 개수 조건을 빼면 안 된다** — 옛 폼이 카드를 지운 채 저장하면 번호가 밀려 **메모가 표시 없이 엉뚱한 모집 건 아래** 나타난다(가장 나쁜 실패). 조건이 있으면 메모가 눈에 보이게 고아가 돼 「삭제된 모집 건의 메모」에 모인다. ⚠️ `mark_orient_card_consumed`(196)·`link_orient_card_to_campaign`(237)·`unlink_orient_card`(238)는 `data` 전체를 덮지 않고 `jsonb_set` 으로 자기 키만 고쳐 uid 를 보존한다 — **새 함수도 같은 방식으로**. ⚠️ **발행 표시(`campaign_id`)는 여전히 순번 기반**(메모는 고유 번호와 공존). 사양서 `docs/specs/2026-08-05-orient-sheet-internal-memo.md`
- 작성 폼 `dev/sales/orient.html`(+ `sales/orient.html`) — sales 정적 배포. **카드형**(카드 N개 아코디언 + **그 아래** 공통 브랜드 1회. ⚠️ **스크롤 추적 `spyTargets` 의 목록 순서가 화면 순서와 같아야 한다** — updateSpy 가 위에서부터 돌다 멈추므로 어긋나면 헤더 제목 추적이 통째로 멎는다.): 가구매·리뷰어=**판매처 Qoo10 고정**·판매 URL(ttp:// 등 자동 보정 + Qoo10 아니면 경고만)·**가격은 판매가만**·리뷰어=리뷰가이드 / 시딩=등급(나노 IG한정·미들메가 다채널)·채널별 가이드·소구·해시태그·촬영가이드(미들메가). 제출 시 항상 읽기전용 미리보기 1회. 자동저장·낙관적 락·만료/소비 진입 분기. **예시 이미지=URL 또는 업로드(카드당 5개)** — `orient-images` 공개 읽기 버킷(마이그200)에 `{token}/{난수}.{ext}` 로 익명 업로드, 정책 `orient_token_can_upload(text)`(SECURITY DEFINER)로 살아있는 토큰만. 🔴 **통의 목록 조회는 관리자만**(472 — 폴더 이름이 곧 작성 토큰이라 「누구나 조회」가 토큰을 내줬다). 업로드는 `upsert:false` 라 조회 권한 없이 된다 — **`upsert:true` 로 바꾸면 업로드가 막힌다**. 이미지는 긴변 2048 압축, 문서는 원본, svg·html 미허용. URL은 `data.cards[].images[].value`(type:'upload'). **리뷰 가이드·금지 표현·추가 안내 3필드는 간단 리치 텍스트**(DOMPurify@3.1.6). 🔴 익명 작성 → 관리자 열람이라 **저장형 XSS 대비 3중 정화**(저장 `richValue`·미리보기 `pvRowHtml`·관리자 `osFieldHtml`+`sanitizeCautionHtml`). 옛 평문 줄바꿈 보존 `richInitial`. **되돌려 보내는 값 3종**: `cardHtml`이 `data-uid`·`data-campaign-id`·`data-linked-existing`를 담고 `collectCard`가 **값이 있을 때만** `uid`·`campaign_id`·`linked_existing` 로 보낸다. 🔴 **값이 없으면 키를 아예 넣지 않는다** — 빈 키면 관리자 화면이 「발행됨」으로 오독하고, 안 실어 보내면 브랜드가 한 번 저장하는 것만으로 **「발행됨」 표시가 조용히 사라진다**. ⚠️**배포 대상이 다른 프로젝트**(`reverb-sales`)라 커밋 머지 ≠ 페이지 반영 — 브라우저로 눈 확인
- `quote_settings`(426) — 견적 기준값. `key` 기본 키·`amount numeric`·`unit CHECK(krw|jpy|rate)`·`label_ko`·`sort_order`·`updated_at`·`updated_by`. RLS SELECT `is_admin()`, 쓰기는 함수만. `quote_settings_history`(key·prev·next·actor·actor_name·at, 추가만). 초기 9행 — 「단순화 2단계」 참조
- **단순화 재설계 1단계(마이그레이션 424·425 — ★운영 완료)**: 새 시트는 **링크 1개 = 형식 1개 + 제품 1개**. 발급 모달에서 형식·시딩 채널(`instagram_feed·instagram_reels·x·tiktok·youtube`, `OS_SEEDING_CHANNELS`)을 정하고 `create_orient_sheet`(현재 원본 **490** — 5인자. 447 이 424 의 4인자에 모집비 직접 지정을, 465 가 발급 때 `uid` 를, 490 이 「모집비 직접 지정은 캠페인 관리자 이상」을 더했다. 465·490 은 `CREATE OR REPLACE` 라 권한 `authenticated` 가 보존된다)가 `data.issued{form_type,channel,issued_at}` + 카드 1개를 만든다. 🔴 **`data.issued` 유무가 새/옛 구조 판별** — 옛 시트는 옛 경로. **서버 키(`issued`·`quote`·`quote_history`·`quote_error`·`notice_ack` — 다섯째는 445, 헬퍼 현재 원본 **445**)는 `save_orient_draft`·`submit_orient_sheet`(425, `_orient_apply_issued_rules`)가 저장된 값으로 되돌린다** — 옛 캐시 폼이 저장해도 안 둔갑한다. `issued` 시트는 `cards[0].form_type`·`seeding.channels` 를 발급값으로 덮고, **제출만** 카드 2개 이상 `cards_limit`·**긴 글 칸 여섯 전부 1,000자**(`guide_too_long`/`appeal_too_long`/`text_too_long`+`field`, 429 — 폼 `textContent` 와 같은 셈법. `LONG_TEXT_FIELDS` · `cardHtmlNew` 카운터 · 서버 검사 **세 곳이 한 세트**). 🔴 임시저장에는 거부를 걸지 않는다(자동저장 보호). 제출 함수 현재 원본 **461**(425 → 427 → 429 → 430 → 446 → 459 → 461 — 옛 번호를 베이스로 잡으면 견적·글자 수 검사·헬퍼·고정 안내 확인이 사라진다). 폼은 `isNewLayout()` 으로 `cardHtmlNew`·`collectCardNew` 로 가른다(옛 요소 `.old-only`). 사양서 `docs/specs/2026-09-08-orient-sheet-simplify-and-quote.md`
- **단순화 2단계 — 견적(마이그레이션 426·427, ★운영 완료)**: 새 구조는 **제출 때** `submit_orient_sheet`(현재 원본 **461**)가 `quote_settings`(426, 조회 `get_quote_settings()` / 수정 `update_quote_setting()` 캠페인 관리자 이상)를 읽어 `data.quote` 스냅샷을 만든다. 시딩은 판매가 미사용, 부가세 `floor`. 🔴 **세트 규칙** — 제출마다 `quote` 또는 `quote_error` 하나만, 이전 판은 `quote_history[]`(`quote_no`=`{orient_no}-Q`, `revision`). 실패 3종 `price_unreadable`·`slots_missing`·`calc_error`(**제출을 막지 않는다**). ⚠️ 425 의 서버 키 보존이 견적 계산보다 **먼저**(반대면 새 견적이 옛 값으로 되돌아간다). 기준 데이터 페인 여덟 번째 탭 「견적 기준값」(`renderQuoteSettingsTable`, 가짜 단가는 노란 「미입력」) — ⚠️ 환율 단위는 `krw`(1엔당 원). `rate` 면 「1000 %」에 1 초과 거부로 수정이 막힌다. 폼: 작성 확인 → **「견적 보기」**(익명 `preview_orient_quote`, **430** — 계산만) → `screenQuote` → 제출 → **완료 화면 `screenDone`**(`submitted` 재진입도)이 견적서를 펼친다. **배송비(선택, 431)** — `sale.shipping_fee`(비우면 키 없음 = 0). 페이백 = **(판매가 + 배송비) × 환율 × 인원**, `quote.shipping_fee_jpy`(시딩 NULL). 🔴 **계산식은 `_orient_compute_quote`(현재 원본 **463** — 443 베이스 — 구간 요금. 448 은 네 번째 구간 이름, **452 는 「판매가」 이름**만 바꿨다) 한 벌** — 제출과 미리보기가 같은 헬퍼(미리보기는 저장 판 + 1). 인쇄는 견적서 **우측 상단 「인쇄 · PDF」 단추**(`renderQuoteDoc`)만 — 🔴 **자동으로 인쇄 창을 열지 않는다**. PDF 파일명 `quoteFileName`(`document.title` 을 `REVERB_{리뷰어|시딩}_{제품명}_{YYMMDD}` 로). 인쇄 규칙 `body.print-quote`·`body.print-done`. 🔴 **견적서 그리는 코드는 `orient.html` 한 벌** — 관리자 쪽 사본 없음. 관리자의 견적서 보기는 `?embed=quote` 모드를 `orientQuoteModal`(iframe)에 띄워 **postMessage 로 견적 내용을 넘긴다**(`osOpenQuoteDoc` ↔ `bootEmbedQuote`). 토큰 없이 **발행·만료 시트와 `quote_history[i]` 도 열린다**. 🔴 **받는 출처는 환경별**(`embedAllowedOrigins`) — 합치면 개발서버가 운영 도메인에 임의 문서를 띄우는 통로가 된다. 준비 신호(`'*'`)에는 **값을 싣지 않고**, 관리자가 **출처를 고정해** 보낸다(`basis` 는 환율·부가세율 둘). 🔴 **인쇄는 새 탭**(`osPrintQuoteDoc` — `window.open`, `noopener` 금지) — iframe 인쇄는 관리자 화면이 통째로 인쇄되고 파일명도 못 정해, 창 안 인쇄 단추는 감춘다(`body.embed-frame`). ⚠️ `showQuoteScreen` 갈래(`preview`·`view`·`embed`)는 **이름으로 지목** — 부정 조건이면 `embed` 에서 「돌아가기」 막대가 켜져 빈 완료 화면으로 간다. ⚠️ 견적서 창은 `z-index:618`(전부 500 이라 안 적으면 ESC 가 뒤 창을 닫는다) · 드래그 목록 제외(다른 출처 iframe 위에서 드래그가 멎는다) · 시트는 `_osDetailSheet` → `_orientSheets` 순. ⚠️ 관리자 화면만 먼저 배포되면 준비 신호가 안 와 6초 뒤 「불러오지 못했습니다」. 🔴 **시딩 채널 단가는 반드시 실제 값으로** — 가짜 값이면 그 금액의 견적서가 브랜드에게 간다
