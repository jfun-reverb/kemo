# Compact instructions

이 프로젝트는 대화가 40만 토큰에 닿으면 자동 요약한다(`.claude/settings.json` 의 `autoCompactWindow`). 요약할 때 반드시 남긴다:
- 지금 하던 일과 다음 단계 · 작업 폴더와 브랜치
- **내가 만든** 미커밋 파일 목록(남의 미커밋과 구분)
- 검증 상태 — 확인한 것은 실행한 명령과 결과 건수와 함께, 안 한 것은 「미확인」으로
- 사용자가 내린 결정과 답을 기다리는 질문

🔴 요약 뒤의 「확인했다」는 옮겨 전한 말이다 — 저장소·데이터베이스 사실로 쓰기 전에 다시 확인한다([[common-multi-session]] 「세션 사이에 오간 말은 저장소의 사실이 아니다」).

**Why:** 2026-10-20 실측 — 응답당 평균 51만 토큰을 다시 읽었고, 30만을 넘은 응답이 재독량의 91%였다. 근거는 메모리 `project_token_usage_rtk_review_2026_10_20`.
