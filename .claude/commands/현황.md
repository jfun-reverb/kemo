# 현황

**지금 돌고 있는 것만** 보여준다. 며칠 조용한 작업 폴더는 빼고, **최근에 실제로 움직인 것**만 남긴다.

## 왜 이 모양인가 (설계 근거)

🔴 **세션에게 물어보지 않고 파일에서 읽는다.** `ListAgents` 로 얻는 `busy`/`idle` 은 **그 순간의 스냅샷이라 보고에 쓰는 순간 이미 낡는다** — 실측(2026-09-01)에서 **10분 사이 같은 도구가 다른 답**을 줬고, 그때 `started 23h ago` 는 **양쪽 다 그대로**였다. 즉 그 숫자는 **「방금 시작」과 「23시간째 멈춤」을 구분하지 못한다.**

→ 대신 **마지막 커밋 시각**을 쓴다. 그것은 **실제로 무언가 일어난 시각**이다.

⚠️ **진행률(%)을 쓰지 않는 이유** — 「대략 70%」는 사람의 판단이라 **틀려도 드러나지 않는다.** 체크박스는 「이 항목이 끝났다」는 사실이라 **항목을 보면 맞는지 알 수 있다.**

⚠️ **못 보는 것** — 아직 커밋하지 않은 조사 중인 세션은 안 잡힌다. 그것까지 보려면 각 세션이 상태를 적는 장부가 필요한데, **이 명령은 저장하는 것이 없다**(그게 이 설계의 장점이다).

## 할 일

### 1. 지금 돌고 있는 작업 폴더

`git worktree list` 로 폴더를 훑고, 각 폴더에서:
- `git -C <경로> log -1 --format="%ct|%ar|%s"` — 마지막 커밋 시각·상대 시각·제목
- `git -C <경로> status --short | wc -l` — 커밋 안 된 파일 수
- **마지막 커밋이 24시간을 넘으면 제외한다** (조용한 폴더는 「지금 돌고 있는 것」이 아니다)

폴더 이름·브랜치·상대 시각·커밋 제목을 보여주고, 커밋 안 된 파일이 있으면 **⚠️ 로 표시**한다.

### 2. 작업표 진행 (있을 때만)

각 브랜치가 만진 사양서를 **자동으로** 찾는다:

```
git log origin/dev..origin/<브랜치> --name-only --format="" | grep "^docs/specs/" | sort -u
```

찾은 파일에 체크박스가 있으면 세어서 `6/10` 으로 보여준다:
- 전체: `grep -cE "^\s*- \[[ x]\]" <파일>`
- 완료: `grep -cE "^\s*- \[x\]" <파일>`

⚠️ **체크박스가 없으면 그 줄을 아예 안 그린다.** 「0/0」 이나 「진행률 없음」을 띄우면 화면만 시끄럽다.

### 3. 열려 있는 병합 요청

`gh pr list --state open` — 번호·브랜치·제목.
⚠️ **오래 열려 있는 것이 드러난다.** 실측에서 3개월 방치된 것이 이 자리에서 발견됐다.

### 4. 지금 켜져 있는 세션 (참고)

`ListAgents` 결과를 **맨 아래에 참고로만** 붙인다.
🔴 **「몇 개가 켜져 있다」까지만 쓰고 `busy`/`idle` 은 그대로 옮기지 않는다** — 위에 적은 이유로 그 값은 말하는 순간 낡는다. 굳이 보여줄 때는 **「조회 시점 기준」임을 함께** 적는다.

## 주의

- ⚠️ **다른 폴더를 조회만 한다.** `git -C` 로 읽기만 하고 **브랜치를 바꾸거나 파일을 건드리지 않는다** — 남의 미커밋이 사라진다.
- ⚠️ 24시간 기준은 임의값이다. 더 좁히고 싶으면 그 자리에서 조정한다.
