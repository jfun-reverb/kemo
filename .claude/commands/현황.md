# 현황

여러 세션을 동시에 돌릴 때 「누가 뭘 하고 있고, 얼마나 왔고, 지금 내 답을 기다리는가」를 한 번에 확인하는 단축키.

## 실행

```bash
node "$CLAUDE_PROJECT_DIR/.claude/scripts/session-status.js"
```

다른 프로젝트 세션까지 보려면 `--all` 을 붙인다.

## 표에 나오는 것과, 그걸 얼마나 믿어도 되나

| 칸 | 어디서 오나 | 믿어도 되나 |
|---|---|---|
| 상태 (작업 중 / 대기 / 내 답 기다림) | Claude Code 가 스스로 기록 | ✅ 항상 정확 |
| 마지막 활동 시각 | 〃 | ✅ 항상 정확 |
| 폴더 · 가지 · 커밋 안 된 파일 수 | 실제 폴더를 그때그때 조회 | ✅ 항상 정확 |
| **일감 이름 · 진행률** | **세션 이름에 사람이 적은 것** | ⚠️ 안 바꾸면 낡는다 → 그래서 「일감표시 갱신 N분 전」을 함께 보여준다 |

「일감 이름 안 붙음」이라고 뜨는 세션은 이름을 자동 꼬리표(`reverb-jp-5b` 같은 것)로 두고 있는 것이다. 그 세션에게 이름을 붙이라고 하면 된다.

## 세션 이름 붙이는 법 (그 세션에서)

```bash
node "$CLAUDE_PROJECT_DIR/.claude/scripts/session-name.js" "회원탈퇴 화면 2/5"
```

형식은 `일감이름 완료/전체`. 단계가 넘어갈 때마다 다시 부른다.

## 경고가 뜨는 경우

- 🔴 **같은 폴더를 두 세션 이상이 쓰고 있음** — 한쪽이 가지를 바꾸거나 되돌리면 다른 쪽 작업이 **경고 한 줄 없이 사라진다.** 커밋 안 된 파일이 함께 표시되면 그만큼이 위험에 놓인 것이다. 작업 폴더를 나누는 게(`/새세션`) 근본 해결이다.
- **열려만 있는 세션** — 6시간 넘게 조용한 세션. 터미널만 떠 있는 상태라 「지금 도는 세션」과 분리해 보여준다. 정리해도 되는지 판단하는 근거.

## 안 나오는 것

- 남은 **시간**은 안 나온다. 어떤 세션도 「앞으로 몇 분」을 정직하게 답할 수 없어서, 넣으면 그 숫자가 곧 거짓말이 된다. 대신 「몇 개 중 몇 개」로 본다.
