# 경쟁·유사 플랫폼 문구 벤치마크 (한·일 랜딩페이지)

> 한국·일본의 인플루언서 체험단·시딩·모니터 플랫폼 랜딩페이지 문구를 조사한 결과.
> 문구를 제안할 때 "실제 업계가 어떤 단어·어투를 쓰는지" 참고용. (조사 시점 2026-07, 실제 사이트 원문 기반)
> ⚠️ 수치·순위("1위"·"4만 명")는 **마케팅 주장**이지 사실이 아니다. 톤·표현만 참고하고 수치는 베끼지 않는다.

## 인플루언서 유치 문구

### 🇰🇷 한국
- **핵심 키워드**: "무료 체험단" · "무료 회원가입" · "무료 등록" · "지금 바로 참여하세요" — 무료 + 즉시 행동을 맨 앞
- **혜택 표현**: 실물+포인트를 구체 금액으로 ("식사권 10만원 + 포인트 40만 지급")
- **신뢰·인기**: "대한민국 대표 / 1위" + 경쟁률 노출("신청 18명 / 모집 5명")
- **CTA**: 로그인 / 회원가입 / 더보기 (매우 간결)
- 출처: revu.net, mrblog.net, reviewnote.co.kr, chvu.co.kr, onepik.kr

### 🇯🇵 일본 (원문 → 한국어 뜻)
- **핵심 소구**:
  - `報酬手数料0円` — "보수 수수료 0엔"
  - `報酬100%` — "보수 100% 수령" (업계 30% 대비 비교표로 제시)
  - `無料登録` — "무료 등록"
  - `かんたん応募` — "간단 응모"
- **모니터형(monipla)**: `商品モニター募集`("상품 모니터 모집") · `無料サンプル`("무료 샘플") · `現品プレゼント`("현품 증정") · `もれなく / 先着 / 抽選`("전원 / 선착순 / 추첨")
- **어투**: **です/ます 경어체 + 느낌표(!) 사용 + 이모지 없음.** `ぜひ`(꼭) · `お願いします`(부탁드립니다) · `様`(님)으로 정중하면서 열정적
  - 예) `TikToker様もぜひ無料登録お願いします！` — "틱톡커님도 꼭 무료 등록 부탁드립니다!"
- 출처: woomy.me, monipla.jp

## 광고주 유치 문구

### 🇰🇷 한국
- **CTA**: "무료 상담하기 / 제안서 받기 / 문의하기 / 광고 문의" — 판매·결제 버튼 없이 **저부담 리드 유도**. 전화·상담시간 함께 노출
- **신뢰·차별**: 인플루언서 규모, 리뷰 품질, 목적별 맞춤(매출/브랜드/글로벌)
- **간편함**: "캠페인 등록 5분이면 OK"
- 출처: biz.revu.net, tagby.io, cheheomin.com, onepik.kr

### 🇯🇵 일본 (원문 → 한국어 뜻)
- `完全無料` — "완전 무료"(월 고정비·성과보수 없음)
- `専任担当者フルサポート` — "전담 담당자 풀서포트"
- `全部まとめて` — "전부 한꺼번에"(원스톱)
- `企業とインフルエンサーの利益を最大化` — "기업과 인플루언서의 이익을 최대화"(양측 소구)
- 출처: woomy.me, find-model.jp

## REVERB 적용 원칙 (조사에서 도출)

1. **일본 인플루언서 화면** = です/ます 경어체 + **느낌표는 OK, 이모지는 지양**(일본 관행). 적극적인 톤을 써도 좋다.
2. **사실 기반 표현으로 규제 회피** — `モニター募集`("모니터 모집")·`現品プレゼント`("현품 증정")처럼 당첨을 단정하지 않는다. 뒷광고 규제와 정합.
3. **"무료 · 간단"을 앞세운다** — 일본·한국 공통으로 `無料登録`·`かんたん応募`("간단 응모")가 초등학생 눈높이 방침과도 잘 맞는다.
4. **광고주 폼(한국어)** = 판매 톤이 아니라 "무료 상담 · 5분 등록 · 문의" 저부담 유도.
5. **수치·순위는 베끼지 않는다** — "1위·N만 명"은 검증 안 된 마케팅 주장. REVERB는 사실만.
6. **"무료"의 조건 주의** — 경쟁사도 "무료"는 특정 요금제 한정인 경우가 많다. 우리가 쓸 땐 조건을 정확히.

⚠️ 뒷광고·표시광고 규제의 구체 조항은 이 조사 범위 밖. 실제 문구 적용 시 `.claude/rules/policy.md` + 별도 법률 확인.
