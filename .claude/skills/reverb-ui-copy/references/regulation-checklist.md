# 문구 규제·과장 억제 체크리스트

> 인플루언서 대상 문구·홍보 문구·메일을 쓸 때 훑는 체크리스트.
> REVERB는 일본 시장이라 뒷광고(스테스 마케팅) 규제와 과장 광고 억제가 걸린다.

## 일본 뒷광고(ステマ) 규제

- 결과물 게시 안내에는 **광고 표기 의무**를 명시한다: `#PR` · `#広告` · `#プロモーション` 중 하나
- "광고인 걸 숨기라"는 뉘앙스 절대 금지
- 협찬·무료 제공 사실을 감추도록 유도하는 문구 금지

## 과장·단정 억제 (인플루언서 화면)

피해야 할 표현:
- "반드시 당첨" · "확실히 받는다" — 선정은 심사 결과라 단정 불가
- "무조건" · "100%" 같은 단정
- "지금 안 하면 손해" · "단 하루" · "마지막 기회" 같은 압박·희소성 조장
- 실제 리워드·조건을 부풀린 표현

권장 방향:
- 사실 그대로 담백하게 ("応募後、審査があります")
- 다음 행동은 부드럽게 유도 ("気になるキャンペーンをさがしてみましょう")
- 명확함 > 후킹

## 개인정보·동의 관련 문구

- 새 개인정보 수집(생년월일·성별 등)·마케팅 동의를 받는 문구는 **무엇을·왜 수집하는지** 쉬운 말로
- 동의는 사용자가 스스로 체크 (기본 체크·강제 동의 유도 금지)
- 수집 항목이 바뀌면 개인정보처리방침 반영이 선행돼야 함 (`.claude/rules/policy.md`)

## 되돌릴 수 없는 동작 문구

삭제·발송·차단·탈퇴·운영 배포 등은:
- 결과를 분명히 알린다 ("この操作は取り消せません")
- 확인 한 단계를 둔다 (버튼 이름을 정확히)

## 접근성 (문구 관점)

- 색·아이콘만으로 뜻을 전달하지 않는다 (텍스트 라벨 병행)
- 에러 문구는 "무엇이 잘못됐고 어떻게 고치는지" 알려준다

## 최종 확인

- [ ] 광고 표기 안내가 필요한 문구인데 빠지지 않았나
- [ ] 단정·압박·희소성 조장 표현이 없나
- [ ] 되돌릴 수 없는 동작에 경고·확인이 있나
- [ ] 동의 유도가 강제적이지 않나
