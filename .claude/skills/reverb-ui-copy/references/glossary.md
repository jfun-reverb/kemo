# REVERB 용어 사전 (화면 문구용)

> 같은 개념을 화면마다 다른 단어로 부르는 것을 막기 위한 표준 표기.
> 새 문구를 쓸 때 여기 있는 개념이면 **반드시 이 표기**를 쓴다. 새 개념이면 여기에 한 줄 추가 제안.

## 캠페인 모집 유형 (가장 헷갈리는 부분)

| 개념 | 관리자 화면(한국어) | 인플루언서 화면(일본어) | 코드값 | 메모 |
|---|---|---|---|---|
| 리뷰어형 | 리뷰어 | モニター | `monitor` | ⚠️ 코드는 monitor, 사람에겐 "리뷰어/モニター". 제품 사서 후기 |
| 기프팅형 | 시딩 / 기프팅 | ギフティング | `gifting` | 제품 무료 제공 |
| 방문형 | 방문형 | 訪問 | `visit` | 매장 방문 후 게시 |

- 관리자 UI 라벨은 "리뷰어/시딩/방문형"으로 통일. "모니터"라는 한국어 라벨은 화면에 쓰지 않는다(코드값일 뿐).
- 인플루언서 화면은 「モニター / ギフティング / 訪問」.

## 상태 라벨 (코드값을 화면에 노출 금지)

| 코드값 | 관리자(한국어) | 인플루언서(일본어) |
|---|---|---|
| `draft` | 준비중 | (노출 안 함) |
| `scheduled` | 모집예정 | 近日公開 |
| `active` | 모집중 | 募集中 |
| `closed` | 모집마감 | 募集締切 |
| `ended` | 종료 | 終了 |
| `expired` | 노출마감 | (노출 안 함) |

## 자주 쓰는 개념 — 표준 표기

| 개념 | 관리자(한국어) | 인플루언서(일본어) |
|---|---|---|
| 신청/응모 | 신청 (관리자는 "신청"·"응모" 혼용 주의 → **신청**으로 통일 권장) | 応募 |
| 결과물 | 결과물 | 投稿 / 結果物 |
| 검수 | 검수 | (인플에겐 "確認中" 등 쉬운 말) |
| 영수증 | 영수증 | レシート |
| 정산/리워드 | 정산 | 報酬 / 精算 |
| 마감일 | 마감일 | 締切 |
| 제출 마감 | 결과물 제출 마감 | 投稿の締切 |

## 표기 통일 (한국어 — 자주 틀리는 단어의 올바른 표기)

- 캠페인
- 콘텐츠
- 메시지
- 햄버거 (메뉴)
- 리뷰어 / 시딩 / 방문형

(잘못된 변형 표기 목록은 `.claude/rules/interaction.md`「한국어 오탈자」 + 오탈자 점검 훅 참조)

## 새 용어를 정할 때 규칙

1. 이미 이 표에 같은 개념이 있으면 **그 표기를 쓴다** (새로 만들지 않는다)
2. 없으면 → 관리자(한국어)·인플루언서(일본어) 양쪽 표기를 함께 정한다
3. 코드값(영어)과 화면 표기(한/일)를 분리한다 — 코드값을 화면에 노출하지 않는다
4. 정한 새 용어는 이 파일에 한 줄 추가 제안 (사용자 확인 후 반영)
