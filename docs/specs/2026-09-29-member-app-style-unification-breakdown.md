## 🧭 배분 제안

- **한 개발 세션이 조각 0 → 6 을 차례로** 맡는다. `dev/index.html` 을 모두 만지므로 두 세션으로 나눠도 이득이 없다(핫스팟 — 병렬 금지).
- 조각마다 **개발서버 캡처 대조 → 사용자 확인 → 운영** 한 번씩. 운영 배포 전 사용자 확인은 매번.
- 조각 0 은 모양을 안 바꾸므로 **10/6 직후 단독으로 먼저** 운영에 내도 된다.
- 조각 5 는 창구 회원 화면 병합(선결 B)이 늦으면 **6 을 앞당기고** 5 를 맨 끝에 둔다. 그때 「마무리」는 5 에 붙인다.
- 메인 세션이 할 것: 화면 일본어 문구가 생기는 조각(0·1·5·6 가능성 높음)에서 `reverb-ui-copy` 스킬, 부품 세부 모양에서 `apple-design` 스킬.
