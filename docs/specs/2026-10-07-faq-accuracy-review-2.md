# 자주 묻는 질문 운영 동작 대조 — 2차 정정·추가안

**작성일:** 2026-10-07
**대상:** 운영 `faq_nodes` 38행(분류 7 + 질문 31) — 2026-10-07 운영 데이터베이스에서 읽기 전용으로 가져옴
**대조 기준:** 운영 코드 `origin/main`(a26b8fbb) · 곧 나갈 코드 `origin/dev`(서비스 문의 여러 대화·문의 화면 정리)
**앞선 정정:** `docs/specs/2026-05-27-faq-accuracy-fix.md`(1차 — 이번 대조에서 그때 고친 내용은 대부분 반영돼 있음을 확인)

## 현재 상태

### 관련 코드·데이터
- 질문 원본은 데이터베이스 `faq_nodes` 행이다. 코드 배포와 무관하게 **관리자 「자주 묻는 질문」 화면 또는 SQL 로 고친다**
- 회원에게 보이는 자리
  - 운영: 캠페인 문의 대화 안 문의 게이트 + 서비스 문의(분류 5·6·7 중 단계가 빈 질문만)
  - 곧 나갈 것: 문의 목록의 「よくある質問」 버튼 → 독립 페이지, 대화 안 「+」 → 아래 창. 노출 위치는 마이그레이션 510 의 체크 칸 둘(`show_in_campaign` · `show_in_service`)로 정한다
- 「직접 문의」(`is_human_handoff`) 질문은 **답변 본문이 화면에 안 나온다** — 누르면 바로 입력 화면으로 간다(`messaging.js` 문의 게이트)

### 이 제안과 충돌 가능성 있는 기존 동작
- 「그 외 문의」·탈퇴 연락처 문안은 **서비스 문의 화면의 탭 이름**에 기댄다. 운영은 「サービスのお問い合わせ」, 곧 나갈 것은 「サービス」 — 문안은 둘 다에 맞게 「サービス」 낱말만 쓴다
- 「최대 금액」 질문의 이동 목적지 `#mypage-settlements` 는 정산 화면 제거(마이그레이션 343)로 **없는 화면** — 누르면 응모이력으로 튕긴다
- 회원 탈퇴는 **시행 전 잠금이 살아 있다** — 탈퇴 질문은 지금 동작 기준으로 쓴다(잠금이 풀리면 다시 고칠 대상: 6-0005·6-0007)

### 가장 큰 어긋남 다섯
1. **결과물 제출 순서** — 답변은 「提出」(제출) 한 번이면 끝난다고 하지만 실제는 「リストに追加」(리스트에 추가) → 「提出する」(제출하기) 두 단계. 「올려두고 제출 안 함」 사고의 원인과 같은 자리
2. **없는 알림을 약속** — 「발송 안내는 앱 알림으로」(배송) · 「심사 결과는 앱 알림으로」(낙선은 알림이 없고 다음 날 아침 메일) · 보수 지급 알림(343 이후 안 감)
3. **정산 화면 이동 버튼이 깨짐** — 「최대 금액」 질문
4. **탈퇴 연락처가 LINE** — 지금 화면은 「お問い合わせ」 버튼으로 안내. 「운영팀이 확인합니다」 조건도 넷 중 셋만
5. **「그 외 문의」가 응모 무관 질문을 캠페인 대화로 보낸다** — 서비스 문의 창구 안내가 없다

## 질문별 정정안

> 표기: 일본어 문안 → 아래 줄에 「뜻:」 한국어. 한국어 판(`body_ko`)은 뜻 줄을 그대로 쓴다.

### 신청·응모

**1-0002 응모 취소 (일부 틀림)** — 메뉴 이름이 「取り消し」 가 아니라 「応募を取り消す」, 모집 뒤 취소 조건이 없음
```
応募の取り消しは、つぎの順番でできます。
1. 下のボタンで「応募履歴」を開きます。
2. 取り消したい応募の「…」ボタンを押します。
3. 「応募を取り消す」をえらび、次の画面で「取り消す」を押します。
募集期間が終わったあとに取り消すときは、理由の入力が必要です。違反の記録になることがあります。
成果物がすでに承認されている応募は、ご自身では取り消せません。下の「直接お問い合わせ」からご連絡ください。
```
뜻: 응모 취소는 다음 순서로 합니다. 1. 아래 버튼으로 「응모이력」을 엽니다. 2. 취소할 응모의 「…」 버튼을 누릅니다. 3. 「응모를 취소한다」를 고르고 다음 화면에서 「취소한다」를 누릅니다. 모집 기간이 끝난 뒤 취소할 때는 이유를 적어야 하고 위반 기록이 남을 수 있습니다. 결과물이 이미 승인된 응모는 직접 취소할 수 없으니 아래 「직접 문의」로 연락 주세요.

**1-0003 취소 후 재응모 (일부 틀림)** — 정원 조건 누락, 버튼 이름
```
応募を取り消したあとでも、つぎのときはもう一度応募できます。
1. そのキャンペーンがまだ募集中のとき
2. 募集人数にまだ空きがあるとき
キャンペーンのページに「再応募する」ボタンが出ます。
募集が終わっているときは、新しく応募できません。
```
뜻: 응모를 취소한 뒤에도 다음일 때는 다시 응모할 수 있습니다. 1. 그 캠페인이 아직 모집 중일 때 2. 정원에 아직 여유가 있을 때. 캠페인 페이지에 「다시 응모하기」 버튼이 나옵니다. 모집이 끝났으면 새로 응모할 수 없습니다.

**1-0011 이메일 인증 (맞음, 보강)** — 다시 보내기 버튼이 없다는 것 추가
- 마지막 줄 → `メールが見つからないときは、迷惑メールフォルダも見てください。メールをもう一度送るボタンはありませんので、それでも見つからないときは「直接お問い合わせ」からご連絡ください。`
- 뜻: 메일이 안 보이면 스팸함도 봐 주세요. 메일을 다시 보내는 버튼은 없으니, 그래도 없으면 「직접 문의」로 연락 주세요.

**1-0012 필수 정보 (일부 틀림)** — 이름 누락, 「未登録」 표시 위치
```
応募の前に、マイページで4つの登録が必要です。
1. お名前（漢字・カナ）
2. SNSアカウント（応募するキャンペーンのSNS）
3. お届け先（郵便番号・都道府県・市区町村・電話番号）
4. PayPalのメールアドレス
足りないものは、応募のときに出る画面に表示されます。メニューにも「未登録」と出ます。
すべて登録すると、応募できます。
```
뜻: 응모 전에 마이페이지에서 4가지를 등록해야 합니다. 1. 이름(한자·가나) 2. SNS 계정 3. 배송지(우편번호·도도부현·시구정촌·전화번호) 4. PayPal 이메일. 빠진 것은 응모할 때 뜨는 창에 표시되고, 메뉴에도 「未登録」(미등록)이 나옵니다. 모두 등록하면 응모할 수 있습니다.

**1-0013 팔로워 부족 (일부 틀림)** — 리뷰어형 이름, 「또는/그리고」 갈래
- 마지막 두 줄 →
```
フォロワーの条件は、キャンペーンで決められたSNSのフォロワー数で確認します。
SNSが複数のときは、どれか1つが条件をこえれば応募できます（キャンペーンによっては、すべてのSNSで条件が必要です）。
「レビュアー」のキャンペーンには、フォロワーの条件はありません。
```
- 뜻: 팔로워 조건은 캠페인이 정한 SNS 의 팔로워 수로 확인합니다. SNS 가 여러 개면 하나만 넘어도 응모할 수 있습니다(캠페인에 따라 모든 SNS 가 넘어야 합니다). 「리뷰어」 캠페인은 팔로워 조건이 없습니다.

**1-0014 이미 응모 (일부 틀림)** — 낙선 캠페인 재응모 불가 누락
- 추가 → `「落選」になったキャンペーンにも、もう一度は応募できません。`
- 뜻: 「낙선」이 된 캠페인에도 다시 응모할 수 없습니다.

**1-0015 모집 마감 (일부 틀림)** — 정원 마감은 리뷰어형만
```
このキャンペーンは募集が終わりました。
1. 「募集締切」… 募集の期間が終わりました。
2. 「募集終了」… 募集人数に達しました（「レビュアー」のキャンペーン）。
どちらも、新しく応募することはできません。
ほかのキャンペーンは、キャンペーン一覧から見られます。
```
뜻: 이 캠페인은 모집이 끝났습니다. 1. 「모집 마감」 … 모집 기간이 끝났습니다. 2. 「모집 종료」 … 정원이 찼습니다(「리뷰어」 캠페인). 둘 다 새로 응모할 수 없습니다. 다른 캠페인은 캠페인 목록에서 볼 수 있습니다.

### 심사·결과

**2-0001 심사 기간 (일부 틀림)** — 낙선은 앱 알림이 없다
- 둘째 줄 → `審査には数日かかることがあります。当選したときはアプリの通知でお知らせします。結果はメールでもお送りします。`
- 뜻: 심사에 며칠 걸릴 수 있습니다. 당첨되면 앱 알림으로 알립니다. 결과는 메일로도 보냅니다.

**2-0002 당첨 확인 (맞음, 보강)** — 마지막 줄 → `当選のときは「当選」と表示され、アプリの通知とメールでもお知らせします。` (뜻: 당첨 시 「当選」으로 표시되고 앱 알림과 메일로도 알립니다.)

**2-0003 선정 안 된 이유 (맞음)** — 고칠 것 없음. ⚠️ 별개: 캠페인 상세 고정 문구 「当選されなかった方への個別のご連絡は実施しておりません」(낙선자에게 개별 연락 안 함)이 **실제로 나가는 낙선 메일과 어긋난다** — 자주 묻는 질문 밖이라 따로 판단

### 결과물 제출

> 공통: 이동 버튼 이름은 「成果物提出を開く」 — 본문의 「成果物提出」 표기를 맞춘다. 「購入型（モニター）」는 화면 이름 「レビュアー」로 통일.

**3-0001 영수증 (일부 틀림)** — 두 단계 버튼, 스크린샷 2단계 누락
```
※ この案内は「レビュアー」のキャンペーン用です。
レシートの提出は、つぎの順番です。
1. 商品を買います。
2. 下の「成果物提出を開く」を押します。
3. レシートの写真をえらびます。
4. 注文番号・買った日・支払った金額の3つを入力し、「リストに追加」を押します。
5. 最後に「提出する」を押します。押すまで、運営には届きません。
金額は、クーポンやポイントを引いた「実際に支払った金額」を入力してください。
レシートが承認されたら、つぎは投稿のスクリーンショットを提出します。
```
뜻: ※「리뷰어」 캠페인용 안내입니다. 1. 상품을 삽니다. 2. 「결과물 제출 열기」를 누릅니다. 3. 영수증 사진을 고릅니다. 4. 주문번호·구매일·결제 금액 3가지를 입력하고 「리스트에 추가」를 누릅니다. 5. 마지막에 「제출하기」를 누릅니다. 누르기 전에는 운영팀에 전달되지 않습니다. 금액은 쿠폰·포인트를 뺀 실제 결제액을 입력하세요. 영수증이 승인되면 다음은 게시물 스크린샷을 제출합니다.

**3-0002 게시물 주소 (일부 틀림)** — 두 단계 버튼, 채널 불일치 차단, 방문형 현장 사진
```
※ この案内は、投稿のリンクを提出するキャンペーン（ギフティング・訪問型）用です。
1. 下の「成果物提出を開く」を押します。
2. 投稿の公開ページのリンクを貼りつけます。Instagram・TikTokなどの種類は自動でえらばれます。
3. 自動でえらばれないときは、種類を自分でえらびます。
4. 「リストに追加」を押してから、「提出する」を押して完了です。
キャンペーンのSNSと違うリンクは登録できません。
訪問型のキャンペーンは、お店の写真も提出してください。
```
뜻: ※ 게시물 주소를 내는 캠페인(기프팅·방문형)용입니다. 1. 「결과물 제출 열기」를 누릅니다. 2. 게시물 공개 페이지 주소를 붙여넣습니다. 종류는 자동으로 골라집니다. 3. 안 골라지면 직접 고릅니다. 4. 「리스트에 추가」 후 「제출하기」를 누르면 완료. 캠페인 SNS 와 다른 주소는 등록할 수 없습니다. 방문형은 매장 사진도 제출하세요.

**3-0003 해시태그 (일부 틀림)** — 유지 기간 구체화
- 3번 → `3. 投稿は、キャンペーンで決められた期間（多くは6か月以上）消さないでください。`
- 뜻: 게시물은 캠페인이 정한 기간(대부분 6개월 이상) 지우지 마세요.
- 대상 줄에 「レビュアー」 포함 여부는 결정 필요(리뷰어형도 게시물을 올림)

**3-0004 기한 경과 (일부 틀림)** — 실제로는 항상 막힘, 「原稿料」 틀린 말
```
提出期限をすぎると、提出できません（差し戻しされたものの再提出だけはできます）。
期限までに提出されないと、報酬をお支払いできないことがあります。
間に合わない事情があるときは、できるだけ早く「直接お問い合わせ」からご相談ください。担当者が確認します。
```
뜻: 제출 기한이 지나면 제출할 수 없습니다(반려된 것의 재제출만 됩니다). 기한까지 제출하지 않으면 보수를 지급하지 못할 수 있습니다. 사정이 있으면 가능한 빨리 「직접 문의」로 상담하세요.
- ⚠️ 이 질문은 「직접 문의」 설정이라 본문이 화면에 안 나온다 — 본문을 보이게 하려면 설정을 끄고 아래 「직접 문의」 버튼을 쓰게 할지 결정 필요

**3-0005 반려 후 재제출 (일부 틀림)** — 고치는 방법, 재제출 뒤 상태
```
成果物が差し戻されたときは、つぎの順番です。
1. 下の「成果物提出を開く」を押します。
2. 画面の上に、差し戻しの理由が出ます。それぞれの項目の下にも理由が出ます。
3. 理由にあわせて直したものを「リストに追加」し、「提出する」を押します。
再提出すると「検査中」になります。
```
뜻: 1. 「결과물 제출 열기」를 누릅니다. 2. 화면 위에 반려 사유가 나오고, 각 항목 아래에도 나옵니다. 3. 사유에 맞게 고친 것을 「리스트에 추가」하고 「제출하기」를 누릅니다. 재제출하면 「검수 중」이 됩니다.

### 배송

**4-0001 제품 도착 (일부 틀림)** — 발송 알림 없음, 유형 이름
- 기프팅 줄 → `■ 商品が届くキャンペーン（ギフティング）：当選のあと、順番に発送します。韓国から送るため、届くまで時間がかかることがあります。個別のご連絡が必要なときは、お問い合わせのメッセージでお知らせします。`
- 뜻: 기프팅: 당첨 뒤 순서대로 발송합니다. 한국에서 보내 시간이 걸릴 수 있습니다. 개별 연락이 필요할 때는 문의 메시지로 알립니다.
- 리뷰어 줄 → `■ 「レビュアー」のキャンペーン：…`(「購入型（モニター）」 대체)

**4-0002 오배송·파손·미착 (일부 틀림)** — 일본어 질문 범위, 배송 지연
