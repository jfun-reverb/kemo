## 1. 메일 함수 「기존 15자리」 — 체크리스트로 그대로 쓰면 양쪽으로 어긋난다

사양서 §3-4 의 ①~⑮ 는 **전부 실재한다**(`reprocessed` 를 기준으로 전수 확인). 다만 **15가 그대로 쓸 숫자가 아니다.**

### 더 있는 것 둘

- **⑯ 감사용 제외 「전」 기록** — `index.ts` 1262~1267행. ⑥(`totalCountRaw`)과 **별개 문장**이고 절 이름을 키로 적는다. 안 고치면 **기록만 옛 절 넷으로 남는다.**
- **⑰ 「4섹션」이라 적은 주석** — 파일 머리말 4·11~16·25행 + 본문 셋(1167 「4섹션 쿼리 병렬」 · 1254 「4섹션 모두 0건」 · 1447 「4섹션 전체 user_id 대상」).

### 해당 없을 공산이 큰 것 셋

- **⑧ 배치 조회 · ⑨ 감사용 필터 · ⑪ 식별자 수집**

새 절은 **서버 함수가 캠페인 단위로 제외·조인을 끝내** 돌려주므로 회원 식별자를 모을 일이 없다. 「15자리 전부 고친다」로 읽으면 **헛일이 셋** 생긴다.

→ **실제 체크리스트는 17자리**(반영 12 + 추가 2 + 「해당 없음」으로 닫는 3).
