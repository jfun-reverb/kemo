## 2. 설계

### 게이트를 어디에 두나 — `switchAdminPane` 이 아니다

`switchAdminPane` 은 **저장 성공 후 목록 복귀**·동시 저장 충돌 복귀·권한 리다이렉트·브라우저 뒤로가기가 전부 지나간다. 거기 두면 **「저장했는데 저장 안 됐다고 묻는」** 모습이 된다.
→ **`navAdminPaneReload`(사이드바 전용 길목) + 나가기 버튼 3곳 + `openEditCampaign` 진입부** 세 자리.

`openEditCampaign` 을 감싼 이유: 이 함수는 목록 더보기·미리보기·진행현황·채널 경고 모달 **네 곳**에서 불린다. 버튼마다 붙이면 하나 빠뜨리는 순간 그 길로 조용히 날아간다.

### 기준값 (이 기능의 핵심)

| 결정 | 이유 |
|---|---|
| **화면(DOM)에서 뜬다** | 데이터베이스 값과 비교하면 리치 텍스트 왕복·번들 청소로 글자가 미세하게 달라져 **폼을 여는 순간** 「바뀜」이 된다. 이 폼에서 이미 두 번 터진 유형 |
| **늦게 도착하는 칸이 채워진 뒤** 뜬다 | 브랜드 드롭다운·행사 묶음·초대 번호가 나중에 온다. 먼저 뜨면 값이 도착하는 순간 「사용자가 고친 것」이 된다 |
| **폼을 열 때마다 맨 앞에서 비운다** | 안 비우면 직전 캠페인 기준값이 다음 캠페인을 잰다(`_recruitTypeBeforeEvent` 와 같은 함정) |
| **어느 폼 것인지 함께 기억**(`_campDirtyPrefix`) | 편집 기준값으로 신규 폼을 재면 **모든 칸이 「바뀜」** 이 된다 |
| **기준값이 없으면 묻지 않는다** | 없어도 원래대로 돌아갈 뿐이다. **거짓 경고보다 미검출이 낫다** — 한 번 헛경고가 나면 그때부터 아무도 안 읽는다 |

### 비교 대상

**넣음** — 일반 입력칸(`id` 없으면 `name` 기준) · 리치 텍스트 3개(`normalizeRichForCompare`) · 번들 3종(`detectSensitiveChange` 재사용) · 이미지(`editCampImgChanged`)
**뺌** — 행사 시간대(즉시 저장) · 파일 선택칸 · 태그 위젯 임시칸

⚠️ **상태 드롭다운(`editCampStatus`)은 빼지 않는다.** 손으로 바꾸는 칸이기도 해서 빼면 진짜 변경을 놓친다. 대신 **노출 토글이 저장에 성공한 직후에만** 기준값의 그 칸을 새 값으로 맞춘다(`syncCampDirtyStatus`).

### 「저장하고 나가기」

경고창을 **먼저 닫고** `saveCampaignEdit()` 을 부른다(확인창 인프라는 결과를 담는 자리가 하나뿐이라 겹치면 서로를 잡아먹는다).
**여기서 화면 이동을 하지 않는다** — 성공하면 저장 함수가 스스로 목록으로 가고, 실패·취소면 폼에 남는 게 맞다. 고친 내용을 들고 화면을 떠나면 그대로 유실된다.

### 안내 문구

행사 시간대·노출 토글을 **이번에 만졌을 때만** 「누른 즉시 저장돼 되돌아가지 않습니다」를 한 줄 붙인다. 「변경한 내용이 사라집니다」로만 두면 사실과 어긋난다.

## 3. ★ 리뷰가 첫 판을 막았다 (NO-GO)

| 결함 | 결과 |
|---|---|
| **번들 비교가 없는 변수를 참조** — 값을 손으로 흉내 내며 `_editCautionSetId` 등 코드베이스에 없는 이름을 씀 | 항상 빈 값이 넘어가, **참여방법·주의사항이 있는 정상 캠페인마다 매번 거짓 경고**. 이 기능이 절대 하면 안 되는 그것 |
| **신규 폼은 기준값을 뜨는 코드가 아예 없었다** | 편집 폼을 한 번 열면 신규 폼에서 **취소만 눌러도 거의 모든 칸**이 변경으로 잡힘. 세션 첫 진입에서는 반대로 **하나도 못 잡음** |
| **`id` 없는 칸을 통째로 건너뜀** | 모집 타입·채널·콘텐츠 종류·채널 결합 — **가장 자주 만지는 칸들**이 안 잡힘 |

→ 각각 ①저장 경로가 쓰는 함수를 그대로 호출 ②신규 폼 기준값 + `_campDirtyPrefix` 가드 ③`name` 기반 키(`name:{name}:{value}`)로 해소.

**교훈: 값을 손으로 흉내 내지 말고 그 값을 만드는 함수를 부른다.** 이름이 하나만 달라도 조용히 항상 참이거나 항상 거짓이 된다.

## 5. 함께 한 것 — 행사 모드 블록 축소 (PR #942)

「오프라인 행사(방문 예약) 캠페인」 블록이 폼 맨 위에서 **모든 신규 등록마다 가장 큰 자리**를 차지하고 있었다(사용자 지적). 꺼져 있을 때는 **체크박스 한 줄**(39px)로 줄이고, 켜면 그대로 펼친다(363px).
⚠️ **자리는 아래로 옮기지 않았다** — 이 체크박스를 켜면 모집 형식이 방문형으로 고정되므로, 모집 형식을 고르기 **전에** 눈에 들어와야 순서가 맞다.
