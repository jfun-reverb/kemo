# 큐텐 리뷰 페이백 — 유사 서비스는 광고 표시·규약 충돌을 어떻게 다루는가
**작성일:** 2026-09-10 · **작성:** 기획 세션 · **요청:** 사용자(「유사 서비스에서 어떻게 대처하고 있는지 면밀히 조사해줘」)
**앞 문서:** `docs/research/2026-09-10-japan-stealth-marketing-regulation.md` §2-4·§7-① — 「리뷰어형은 일본 법(광고 표시 의무)과 큐텐 규약(대가 수반 리뷰 삭제 대상)이 충돌한다」에서 이어진다. **코드는 바꾸지 않는다.**

> ⚠️ 조사 에이전트 4개(일본 모니터 플랫폼 안내 / 큐텐 정책·집행 / 플랫폼 공식 프로그램·크로스보더 대행사 / 포인테일·챌린저스·glovv 집중 — 사용자 추가 지시)가 2026-09-10 에 확인한 것 + 사용자가 2026-09-08 에 찍어 둔 포인테일 브랜드 화면 캡처 16장. 로그인·앱 전용이라 원문을 못 연 자리는 「3자」로 표시했고 §5 에 모아 두었다. 「없다」가 아니라 「찾지 못했다」로 읽을 것.

## 0. 한 장 요약

1. **일본의 주요 모니터·체험단 플랫폼은 EC 사이트 리뷰란(Amazon·楽天·Qoo10)에 쓰게 하지 않는다.** 확인한 9개 중 EC 리뷰란을 시키는 것은 **큐텐 공식 샘플마켓 1개**(플랫폼 자체 프로그램) + 조건부 1개(ふぁんくる — 3자 기술만)이고, 구매는 EC 에서 시키되 EC 리뷰란은 안 시키는 곳이 2개(モニタダ 는 **리뷰를 SNS·口コミ 사이트로**, TryNow 는 **리뷰 자체를 임의**로), 4개는 SNS·자사 사이트에만 쓰게 하며, 1개(トラミー)는 SNS 중심이나 구매형 유무를 확인 못 했다. 이유는 하나다 — **대가 리뷰는 Amazon(Vine·2026 브랜드 미션 외 전면 금지)·楽天(환급 조건 리뷰 명문 금지)·Qoo10(대가 수반 리뷰 게재 제한) 셋 다 규약(문서)상 위반이라, 표시 문구를 어떻게 적어도 해소되지 않는다.**
2. **큐텐 규약은 「문서상 금지, 실무상 방치」다.** 「対価を伴うレビュー」 금지는 공개 문서 중에서는 **구매자 헬프**에만 있고(판매자 관리 화면 로그인 영역은 못 봤다 — §5) 조치도 「게재 제한·삭제될 수 있다」에 그친다. 출점자 규약에는 리뷰 조항이 없고, 판매 금지 사유는 「고의적 사쿠라·허위 리뷰」다. 큐텐 자신이 판매자 관리 화면에서 **「리뷰 쓰면 판매자 부담 포인트」를 공식 판매 도구**로 제공하고 공식 사례집이 그것을 권장한다. **대가 리뷰를 이유로 판매자·리뷰가 제재된 공개 사례는 일본어·한국어 어디서도 찾지 못했다.** 제재로 보이는 것은 한국 판매자 커뮤니티 전언 1건뿐 — 「해외 결제·지인 구매」가 허위 주문 탐지에 걸린 것으로 보이는 구매자 계정 정지다.
3. **우리와 같은 구조의 경쟁사(포인테일·Challengers·HARUPO·Adtoolglobal) 어디서도 공개 자료에서 광고 표시 안내를 찾지 못했다**(앱 안 미션 카드는 로그인 뒤, Adtoolglobal 캠페인 페이지는 403 이라 확인 못 함). Challengers 는 큐텐 메가할인에 맞춰 「0엔 챌린지」를 공개 진행하고, 포인테일은 「가이드라인 100% 준수」를 내걸지만 어느 가이드라인인지 밝히지 않는다. 차단된 흔적은 찾지 못했다. 즉 공개 자료 기준으로 **「표시 안내 없는 큐텐 리뷰 페이백」이 업계 관행**이고(리뷰 본문 실물은 확인 못 했다 — §2-3), **그 관행의 법적 근거는 없다.** ⚠️ 포인테일의 한국 모회사 서비스(퍼그 제로)는 「리뷰 내 공정위 문구 삽입」을 방침으로 명시한다 — 같은 회사가 한국에서는 표시하고 일본에서는 공개 자료에 그 조항이 없다. glovv 는 큐텐 리뷰 서비스가 아니다(인스타 릴스 제작 중개).
4. **EC 리뷰란에 표시가 시스템으로 붙는 모델은 플랫폼 자체 프로그램뿐** — 큐텐 샘플마켓(시스템 문구 「該当レビューはサンプルマーケットで商品を無償提供された当選者のレビューです」 + 본문 첫머리 「サンプルマーケットで商品を無償で頂きました」 — 첫머리 문구는 3자 2건 일치), Amazon Vine(라벨), 쿠팡체험단(배지 + 문구). 외부 사업자로는 TryNow 가 「Amazon 리뷰 본문에 쓴다면 첫머리에 【PR：○○社モニター】」 형식을 권고하지만 리뷰 의뢰 자체를 안 하는 설계다. SNS 게시물 쪽은 「#PR 선두」·「〇〇から提供」 문두 문장 관행이 확립돼 있다(§1). 판매자가 큐텐 리뷰에 붙일 수 있는 「PR」 표시는 공개 가이드에서 찾지 못했다.
5. **우리처럼 외부 플랫폼이 큐텐 구매 리뷰 + 페이백을 시키면서 리뷰 본문에 대가 관계를 표시하고 규약까지 지킨다고 공개한 사례는 찾지 못했다.** 이 조사가 「어떻게 해야 안전한가」에 준 답은 **「안전한 정답이 없다」**이고, 남는 것은 어느 위험을 안고 어느 위험을 없앨지의 사업 판단이다(§4).

## 2. 큐텐 자체 — 규약·집행·공식 프로그램 (조사 B)

### 2-1. 규약이 어디에 어떻게 적혀 있나

| 문서 | 리뷰 관련 조항 | 조치 |
|---|---|---|
| 구매자 헬프 「レビュー投稿の際はご注意ください」 | 「第三者へ依頼したレビュー投稿や、**対価を伴うレビュー投稿**」「実際に使用していない商品」「レビュー順位・評価を操作する行為」는 「掲載が制限または削除される場合があります」 | **리뷰 게재 제한·삭제**만. 판매자 벌칙 없음 |
| 출점자 규약 제12조(금지행위) | **리뷰 조항 없음**(허위 주문·직거래 유도·원산지 허위 등 8항목) | — |
| 판매 금지 상품 가이드(QSM PDF) | 「虚偽取引及び故意的なやらせレビュー、虚偽レビュー掲載商品」 | 상품 광고 삭제·판매 중지·거래 취소·**판매자 자격 정지** |
| 회원 규약 제16조 | 일반 조항(법령 위반·부정 이용 금지). 「대가」「의뢰」 단어 없음 | 계정 이용 제한 |
| Qoo10大学(공식 노하우) 2026-07 | 리뷰를 **상품 페이지에 인용**할 때 약사법·경품표시법 위반 위험 안내. 대가 리뷰·체험단·PR 표기는 다루지 않음 | — |

→ 「대가 수반 리뷰」 금지는 구매자 쪽 헬프 한 곳이고, 판매자에게 무거운 조치가 걸리는 문구는 「고의적 사쿠라·허위 리뷰」다. **우리 리뷰어형(실구매 + 실사용 + 페이백)은 「대가 수반」에는 걸리지만 「허위·사쿠라」는 아니다** — 이 차이가 실무상 집행이 없는 이유로 보인다(추정).

### 2-2. 큐텐이 스스로 하는 것

- **판매자 관리 화면 「条件つき特典」** — 「리뷰 작성 시 / 프리미엄 리뷰 작성 시」 판매자 부담 Q포인트 10~90,000P 지급 설정. Qoo10大学 공식 사례집(2023-08)이 「リビューの作成率が通常よりも50％以上増加」로 권장. **라벨 없음.**
- **플랫폼 원자 Q포인트** — 리뷰 5P·사진 +5P, 메가할인 때 추가. 라벨 없음.
- **サンプルマーケット**(2021-05~) — 판매자 전시비 무료(상품·배송비 부담), 응모·추첨, 무상 제공, 30일 내 리뷰 필수. **리뷰에 시스템 문구 자동 부착 + 본문 첫머리 문구 규칙.** 2021-05~2025-10 누적 등록 상품 약 3,100개 중 한국 제품 72%, 한국 제품 리뷰 28만 건(eBay Japan 발표, 한국 보도).
- **Sample House**(2026-10 오프라인 체험 시설 예정) — 리뷰 라벨 여부 미기재.

→ **큐텐은 자기 도구(条件つき特典·Q포인트) 안의 「리뷰에 대가」는 정상 영업으로 취급하면서, 무상 제공 리뷰(샘플마켓)에만 라벨을 붙인다.** 판매자가 임의로 붙일 「PR」「提供」 플래그는 공개 가이드에서 찾지 못했다(로그인 영역은 §5).

### 2-3. 집행 실태

- **대가 리뷰로 판매자·리뷰가 제재된 공개 사례: 찾지 못함**(일본어·한국어 보도·블로그·커뮤니티). 컨설팅사들은 「불정 검지·계정 정지 가능」이라 경고하지만 근거 사례를 들지 않는다.
- 제재로 보이는 것 1건(한국 판매자 커뮤니티 전언): 한국에서 결제한 지인 구매가 **구매자 계정 정지** — 리뷰가 아니라 **허위 주문(결제지 이상) 탐지**로 보인다. 같은 글이 「Amazon 은 리뷰 유도를 막지만 큐텐은 그렇지 않다」고 적는다.
- 페이백 리뷰 앱(Challengers·HARUPO)이 공개적으로 돌고(Challengers 는 메가할인 때 「0엔 챌린지」), 한국 프리랜서 장터에 「큐텐 실구매 리뷰 120건」 상품이 팔리는데도 차단 흔적을 찾지 못했다.
- 샘플마켓 밖 큐텐 리뷰에 「#PR」「提供品」 표기가 있는지는 **확인 못 함**(상품 페이지가 외부 도구에서 안 열림). 페이백 앱 이용자 후기에는 PR 표기 언급이 한 건도 없다.

→ **집행이 있다면 「허위 주문·결제지 이상·단기 대량 리뷰」 같은 거래 이상 탐지 쪽**이지 「대가·표시 누락」 판정이 아니다(추정). 우리가 실제로 걸릴 지점은 「대가를 줬다」가 아니라 **한 계정·한 결제원으로 몰리는 구매 패턴**이다.

## 4. 우리 리뷰어형에 대입 — 선택지와 위험 배분

전제(앞 문서 §2-4): 스테마 고시상 우리 리뷰어형은 「사업자의 표시」이고 리뷰 본문에 표시가 있어야 통과한다. 큐텐 규약상 대가 리뷰는 표시 유무와 무관하게 게재 제한 대상이다.

| 선택지 | 무엇 | 없애는 위험 | 남는 위험 | 근거·선례 |
|---|---|---|---|---|
| **(가) 리뷰 첫머리 표시 문장 필수** | 큐텐 샘플마켓 문구를 본떠 「〇〇の依頼を受け、購入代金の負担を受けて投稿しています」 계열을 리뷰 첫머리에 필수 안내 + 검수에서 확인 | 스테마 고시 위반(브랜드 처분) — **그 문장이 「명료한 표시」로 인정된다는 전제**이고 이것이 변호사 확인 대상 | 큐텐 규약(대가 리뷰 게재 제한 — 공개된 집행 사례는 찾지 못함) + 구매 패턴 이상 탐지(§2-3, 표시 유무와 무관). 표시가 붙은 리뷰가 오히려 큐텐 눈에 띌 가능성은 추정 | 샘플마켓이 같은 형식의 문구를 큐텐 리뷰란에 붙이고 있어 **큐텐 리뷰란에 「제공받아 씀」 문장이 존재하는 것 자체는 큐텐이 허용하는 형식**이다 |
| **(나) 현행 유지(표시 안내 없음)** | 경쟁사 관행 그대로 | 없음 | 스테마 고시 위반 + 큐텐 규약(대가 리뷰) + 구매 패턴 탐지. 처분 대상은 브랜드이고, SNOW 건처럼 한국 본사도 공동 명령을 받을 수 있다 | 포인테일·Challengers·HARUPO·Adtoolglobal 전부 이 상태(공개 자료 기준). 포인테일은 계약서로 법적 책임을 브랜드에 넘긴다. 법적 근거 없음 |
| **(다) 구매는 큐텐, 리뷰는 SNS·口コミ 사이트로** | モニタダ 모델(TryNow 는 리뷰 자체를 임의로 둔 변형) — 큐텐 리뷰란을 요구하지 않고 인스타·X·@cosme·LIPS 게시물로 대체(영수증 + 게시물). 표시는 채널 관행대로 — 인스타·X 는 「#PR 선두」 또는 문두 「〇〇から提供」 문장, @cosme 는 입수처 플래그, LIPS 는 「#提供/#PR + 브랜드명」(§1) | 큐텐 리뷰 규약 위험(대가 리뷰) + 표시 위치 문제(SNS 는 관행 확립) | 구매를 큐텐으로 보내는 한 **구매 패턴 탐지 위험은 남는다**(§2-3). **브랜드가 원하는 것이 큐텐 리뷰란 평점·건수**라면 상품성이 없어진다. 우리 리뷰어형 캠페인의 정의가 바뀐다 | 같은 모델은 モニタダ(TryNow 는 변형) — §1 의 9개 중 EC 리뷰란을 확실히 시키는 곳은 플랫폼 공식 프로그램 1개뿐이고, EC 구매를 시키는 외부 사업자 3곳 중 2곳(モニタダ·TryNow)이 EC 리뷰란을 피하고 1곳(ふぁんくる)은 조건부로 시킨다(3자) |
| **(라) 큐텐 공식 샘플마켓 병행 안내** | 브랜드에 샘플마켓(무상 제공·라벨 자동) 사용을 권하고, 우리는 SNS 시딩·현장 사진 쪽에 집중 | 규약·고시 둘 다 | 페이백 모델 매출이 빠진다. 샘플마켓은 무상 제공만이라 「실구매 리뷰」가 아니다 | 한국 제품이 샘플마켓 등록의 72% |

**조사가 답한 것** — 「어디에도 안전한 정답은 없다」. (가)는 법을 지키고 규약을 어기는 선택, (나)는 둘 다 어기는 선택, (다)·(라)는 둘 다 지키되 사업 모델을 바꾸는 선택이다. **집행 실태**(큐텐은 대가 리뷰 제재 공개 사례를 찾지 못함 — 구매 패턴 탐지로 보이는 계정 정지 전언 1건뿐 / 소비자청은 매년 처분·한국 본사 공동 명령 선례)로 보면 **실체가 있는 위험은 법 쪽**이다.

**기획 권고** — (가)를 기본으로 두되 **변호사 확인 1건**(「큐텐 리뷰란에 의뢰·페이백 사실을 적은 문장이 소비자청 운용기준의 「명료한 표시」로 인정되는가 — 샘플마켓 문구가 선례)을 거치고, (다)를 **브랜드가 큐텐 평점을 원하지 않는 캠페인의 선택지**로 오리엔시트에 추가하는 것이 현실적이다. ⚠️ 이것은 권고이지 결정이 아니다 — 사업 모델의 근간이라 사용자가 정한다.
