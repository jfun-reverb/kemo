# 운영현황 「일정」 뷰(간트) — 보기 편의 기능 조사
**조사일:** 2026-09-07 · **조사:** 개발 세션(조사 에이전트) · **대상 화면:** `dev/js/admin-brand-ops.js` 「일정」 절

> 사용자 요청 「간트차트를 좀 더 편하게 볼 수 있으면 좋겠다 — 조사해 달라」. 다른 일정 도구의 보기 편의 기능을 훑고, 우리 화면(캠페인 1건 = 1행, 흑백 기준, 데이터베이스 변경 없이 화면만)에 맞는 것을 추렸다.

## 먼저, 현재 화면의 빈틈(코드 확인)
- **시간축 머리글이 세로 스크롤 때 안 붙었다** — `.gantt-head{position:sticky;top:0}` 인데 세로 스크롤을 바깥 페인이 맡아 10행쯤 내려가면 월·주 눈금이 사라졌다. (→ 같은 날 수정: 간트 상자가 세로 스크롤을 맡고 화면 높이에 맞춘다)
- 하루 10px 고정·12주 — 두세 달짜리 캠페인이 잘리고 넓은 모니터에서 오른쪽이 빈다. (→ 줌 단위)
- 왼쪽 고정 열 약 840px — 노트북에서 시간축이 400~600px 밖에 안 남는다. (→ 왼쪽 열 접기)

## 도구별 편의 기능 (우리에게 맞는지)
| 도구 | 기능 | 판단 |
|---|---|---|
| Asana Timeline | 줌 단위 선택(일~연) · 색 기준 선택 · 날짜 없는 항목 목록 | 줌은 맞음(3단이면 충분). 색 기준은 흑백 기준과 충돌. 날짜 없음은 이미 행 안에 표기 |
| monday.com Gantt | 줌 · 오늘 · 주말 숨김/표시 · 그룹 접기 · 막대 이름표 · 자동 맞춤 · 기준선·의존선·임계 경로 | 주말 음영·그룹 접기 맞음. 기준선(데이터베이스 필요)·의존선(캠페인끼리 선후 관계 없음)은 안 맞음 |
| Notion Timeline | 줌 · Today · 왼쪽 표 접기 · 표시 항목 선택 · 속성별 그룹 · 불러올 개수 제한 | 왼쪽 표 접기·그룹 맞음. 개수 제한은 우리 「종료 포함」과 같은 발상 |
| Jira Timeline | 줌 · Today · 완료 숨김 · 진행률 막대 · 상태별 색 | 완료 숨김 = 「종료 포함」. 진행률은 왼쪽 숫자 3종이 대신 |
| ClickUp Gantt | Ctrl+휠 줌 · 화면 맞추기 · 주말 숨김 · 내보내기 | 화면 맞추기·주말 맞음. 내보내기는 인쇄용 스타일이 관리자 화면에 없어 비용 큼 |
| TeamGantt | 줌 · 열 표시/숨김 · 막대 위 표시 항목 · 그룹 접기 · 인쇄 | 열 표시/숨김·그룹 접기 맞음 |
| Linear Timeline | 줌 · 오늘 · **마우스 따라오는 날짜 안내선** · 왼쪽 목록 접기 · 화면 밖 항목 표시 · 마일스톤 | 날짜 안내선이 가장 맞음(빈칸에서도 며칠인지 앎). 화면 밖 표시 = 우리 가장자리 마커 |
| GitHub Projects Roadmap | 줌 · 세로 표시선 · 그룹 · 슬라이스 | 세로 표시선은 참고. 슬라이스는 회사 필터가 대신 |
| Google Sheets 간트 템플릿 | 주말 열 음영 · 오늘 열 강조 | 주말 음영 그대로 맞음 |

출처(요약): Asana 포럼(줌·색·미배정), flowfam/ProjectManager 의 monday 가이드, Notion 도움말 Timelines, Atlassian 지원(뷰 설정), UpSys 의 ClickUp 가이드, TeamGantt 지원(View Options), Linear 변경 로그 2024-02·Timeline 문서, GitHub Docs(Roadmap 레이아웃), Spreadsheet Point. monday·ClickUp 공식 지원 문서는 접근이 막혀 2차 자료를 썼다.
