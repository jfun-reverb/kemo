연령 정책·메시지 자동 번역 시행 안내

오늘(7월 22일)부터 두 가지 기능이 새로 열렸습니다.

1. 연령 정책 (만 18세 이상)

  • 신규 회원가입·캠페인 응모 시 생년월일과 성별을 입력받습니다.
  • 만 18세 미만은 캠페인 응모가 자동으로 제한됩니다.
  • 관리자가 따로 켜거나 조작할 필요 없이 시스템이 자동으로 적용합니다.

2. 메시지 자동 번역

  • 응모건 메시지에서 관리자(한국어)와 인플루언서(일본어)가 서로 다른 언어로 써도, 상대방 언어 번역이 자동으로 함께 표시됩니다.
  • 원문과 번역문이 같이 보여, 별도 번역기 없이 바로 소통할 수 있습니다.

영향 범위: 인플루언서 앱(가입·응모·메시지)과 관리자 메시지 화면. 운영서버 반영 완료.
