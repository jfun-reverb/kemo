# 캠페인 삭제·복원 방식 변경 및 화면 개선

2026년 7월 23일 업데이트가 반영됐습니다. 관리자 페이지 기능이 아래와 같이 바뀌었습니다.

## 주요 변경 내용

- **결과물 관리·신청 관리에 상태별 탭 추가** — 여러 개를 고르는 필터 대신, 탭을 눌러 상태를 한 번에 바꿔 볼 수 있습니다. (결과물 관리 = 인증 상태 / 신청 관리 = 심사중·승인·미승인·취소)
- **캠페인 삭제가 '보관 삭제'로 변경** — 삭제한 캠페인은 캠페인 목록의 「삭제됨」 탭에 30일간 보관되며, 그 안에는 복구할 수 있습니다. 30일이 지나면 자동으로 완전히 삭제됩니다.
- **캠페인 제목 클릭 → 진행현황 바로 열기** — 캠페인 목록에서 제목을 누르면 그 캠페인의 신청자·모집현황(진행현황) 화면이 바로 열립니다.
- **등록자·삭제자 기록** — 캠페인을 누가·언제 등록했는지, 누가·언제 삭제했는지가 기록되어 「삭제됨」 탭에서 제목을 누르면 확인할 수 있습니다. (등록자는 오늘 등록분부터 기록됩니다.)

## ⚠️ 캠페인 삭제·복원 시 꼭 알아두세요

> **캠페인을 삭제하면 응모자(인플루언서)의 신청 내역과 결과물은 그 즉시 완전히 삭제됩니다.**
>
> 「삭제됨」 탭에서 복구하더라도 **캠페인 설정(제목·모집조건 등)은 되살아나지만, 삭제할 때 지워진 신청·결과물은 되돌릴 수 없습니다.** 즉 복구되는 것은 캠페인 정보뿐이고, 응모자 명단·제출물은 복구되지 않습니다.
>
> 30일이 지나면 「삭제됨」 탭에서도 자동으로 완전히 사라집니다.
>
> 정산(리워드 지급)이 걸린 캠페인은 실수로 지워지는 것을 막기 위해 삭제 자체가 되지 않습니다.

이 안내는 삭제 확인 창에도 표시되지만, 되돌릴 수 없는 동작이라 공지로도 안내드립니다.

**영향 범위**: 관리자 페이지 한정. 인플루언서 앱 화면에는 변화가 없습니다.
