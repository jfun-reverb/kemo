회원가입 방식이 바뀝니다 — 이메일 인증번호 확인 (10월 13일부터)

10월 13일부터 인플루언서 회원가입 화면이 이렇게 바뀝니다.

  1. 회원이 이메일을 입력하고 「認証する」(인증하기)를 누릅니다.
  2. 메일로 6자리 인증번호가 옵니다. 번호를 넣고 「確認」(확인)을 누릅니다.
  3. 번호가 확인돼야 「登録する」(가입하기) 단추가 켜집니다.
  4. 가입하면 바로 로그인 상태가 됩니다. 확인 메일의 링크를 누를 필요가 없어집니다.

번호는 10분 동안만 쓸 수 있습니다. 시간이 지나면 「再送信」(다시 보내기)로 새 번호를 받습니다. 다시 보내기는 60초 뒤부터, 한 주소에 1시간 5번까지입니다.

이미 가입한 주소로 가입하려고 하면

  • 화면에는 새 가입과 똑같이 「보냈습니다」가 뜹니다.
  • 메일은 번호 대신 「이미 가입되어 있습니다 → 로그인 / 비밀번호 재설정」 안내가 갑니다.
  • 번호 입력칸 아래에는 「번호 대신 '이미 가입되어 있습니다' 메일을 받으신 분은 여기서 로그인」 안내가 늘 보입니다.

함께 바뀌는 것

  • 이메일 인증을 마치지 않은 계정은 자동으로 지워집니다. 예전 방식으로 가입하고 확인 링크를 누르지 않은 계정이 대상입니다. 마지막 확인 메일을 보낸 날부터 7일이 지나면 정리됩니다. 응모 등 다른 기록이 있는 계정은 지우지 않습니다.
  • 비밀번호 찾기 화면은 언제나 같은 문구를 보여줍니다. 등록된 주소인지와 관계없이 「등록된 계정이라면 메일을 보냈습니다」가 뜹니다. 계정이 있는지 다른 사람이 알 수 없게 하려는 것입니다.

관리자 화면에서 달라 보이는 것

  • 인플루언서 목록에서 이메일 인증을 안 한 계정이 점차 사라집니다. 오류가 아닙니다.
  • 메타 광고 관리자의 「등록 완료」 이벤트 수가 약 절반으로 보입니다. 가입이 줄어든 것이 아니라 가입 한 번에 이벤트가 2건에서 1건으로 바뀌었기 때문입니다. 광고 담당자는 참고해 주세요.

회원 문의가 오면

  • 「번호가 안 와요」 — 스팸함·프로모션함 확인을 안내합니다. 휴대폰 회사 메일(docomo·au·softbank 등)이면 globalreverb.com 메일을 받도록 수신 설정을 안내합니다. 그래도 안 오면 1분 뒤 「再送信」(다시 보내기).
  • 「번호 대신 '이미 가입되어 있습니다' 메일이 왔어요」 — 이미 가입된 주소입니다. 로그인하고, 비밀번호가 기억나지 않으면 「パスワードを忘れた方」(비밀번호를 잊으신 분)으로 재설정하도록 안내합니다.
  • 「예전에 가입했는데 확인 링크를 안 눌렀어요」 — 새 화면에서 같은 주소로 인증번호를 받아 다시 가입하면 됩니다. 예전 미완료 계정은 자동으로 정리됩니다. 다시 가입이 안 되면 운영팀(개발 담당)에 알려 주세요.
  • 「번호 시간이 지났어요」 — 「再送信」(다시 보내기)로 새 번호를 받으면 됩니다.

영향 범위: 인플루언서 회원가입·비밀번호 찾기 화면과 가입 메일. 기존 회원의 로그인은 그대로입니다.
