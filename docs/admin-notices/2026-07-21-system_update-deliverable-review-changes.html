결과물 검수 화면 변경 안내 (검수 대상·대기 배지)

어제(7월 21일) 결과물 검수와 관련한 화면이 개선됐습니다. 검수 담당자는 아래 변화를 숙지해 주세요.

1. 인플루언서의 응모가 반려·취소되면, 그 응모에 딸린 결과물은 "검수 불필요"로 자동 표시

  • 인플루언서가 캠페인에 낸 응모(신청)를 관리자가 한 번 승인했다가 나중에 반려하거나, 인플루언서 본인이 그 응모를 취소한 경우 — 그 응모에 딸린 결과물(영수증·게시물)은 더 이상 검수할 필요가 없으므로 검수 대상에서 빠지고 "검수 불필요"로 표시됩니다.
  • 그 응모를 다시 승인하면, 결과물이 검수 대상으로 자동 복원됩니다. (인플루언서에게 결과물을 다시 제출받을 필요 없음)
  • "검수 불필요"로 표시된 건은 검수 창에서 승인·반려·되돌리기 같은 검수 동작이 막히고 안내 문구가 뜹니다.

2. 검수 목록에 "검수 불필요 포함" 토글 추가

  • 결과물 목록 위에 "검수 불필요 포함" 토글이 생겼습니다. 기본은 켜짐(모두 보임)이고, 끄면 검수 불필요 건이 숨겨집니다.

3. 사이드바 "검수대기" 숫자가 정확해졌습니다

  • 예전에는 다시 제출로 쌓인 지난 기록까지 세어 실제보다 크게 나왔습니다(예: 실제 몇 건인데 31로 표시).
  • 이제 신청 1건 단위로 정확히 셉니다. 그래서 숫자가 줄어 보일 수 있는데, 오류가 아니라 정상입니다.
  • 배지 숫자를 클릭하면 검수대기 건만 바로 걸러 볼 수 있습니다.

4. 송금 완료된 건은 신청 반려가 막힙니다 (실수 방지)

  • 이미 리워드 송금이 끝난 신청은 반려·되돌리기가 자동으로 차단되고 안내가 뜹니다. (지급 후 상태가 어긋나는 사고 방지)

영향 범위: 관리자 결과물 검수 화면. 운영서버 반영 완료(7월 21일).
