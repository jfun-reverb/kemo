가장 먼저 알아두실 것 — 리뷰어형 지급 금액이 바뀝니다

지금까지는 캠페인에 적힌 상시가를 그대로 돌려드렸습니다. 앞으로는 인플루언서가 실제로 결제한 금액을 돌려드립니다. 다만 상시가보다 비싸게 산 경우에는 상시가까지만 드립니다.

예를 들어 상시가가 3,200엔인 캠페인에서

  • 2,000엔에 샀다 → 2,000엔 지급
  • 3,200엔에 샀다 → 3,200엔 지급
  • 4,000엔에 샀다 → 3,200엔까지만 지급

원래 실무에서 영수증 금액대로 송금해 오셨는데, 시스템 계산과 화면 문구만 상시가로 되어 있었습니다. 이번에 그걸 실무에 맞춘 것입니다.

인플루언서에게 보이는 문구가 바뀝니다

  • 캠페인 상세 화면: 「3,200엔 페이백」 → 「구매 금액을 페이백 (최대 3,200엔)」
  • 화면 아래 고정 바: 「페이백 (최대 3,200엔)」 (짧은 형태)
  • 캠페인 목록 카드: 「제품 무상 제공」 → 「페이백 (최대 3,200엔)」
  • 캠페인 홍보 메일: 상세 화면과 같은 문구
  • 활동 관리의 영수증 입력칸 아래: 「여기 적은 금액이 그대로 송금됩니다」 안내가 새로 붙습니다

카드의 「제품 무상 제공」은 원래 잘못된 표기였습니다. 리뷰어형은 인플루언서가 자기 돈으로 사고 나중에 돌려받는 방식인데 무상으로 받는 것처럼 적혀 있었습니다. 이번에 함께 고쳤습니다.

예상되는 문의와 답변

「최대 3,200엔이라고 했는데 왜 2,000엔만 들어왔나요?」
실제 결제하신 금액을 돌려드립니다. 영수증에 2,000엔으로 적혀 있으면 2,000엔이 지급됩니다. 「최대」는 그보다 비싸게 사셔도 그 금액까지만 드린다는 뜻입니다.

「영수증 금액을 잘못 적었어요」
아직 송금 전이면 운영진이 고칠 수 있습니다. 고치면 지급 금액도 자동으로 다시 계산됩니다. 이미 송금이 끝났거나 보류·취소된 건은 고칠 수 없습니다.

「자주 묻는 질문」에도 같은 내용의 항목이 새로 추가됐습니다.

지금은 인플루언서가 정산 금액 화면을 볼 수 없습니다

정산 내역은 아직 인플루언서에게 잠겨 있고, 자동 등록도 꺼져 있습니다. 지급은 지금처럼 운영진이 직접 확인해서 처리하시면 됩니다. 위 문구 변경만 인플루언서 화면에 보입니다.

새 기능 — 오프라인 팝업 방문 예약

행사장에 손님을 받는 캠페인을 만들 수 있게 됐습니다. 새 모집 형식이 아니라 방문형 캠페인에 「행사 모드」를 켜는 방식입니다.

  1. 캠페인 등록·편집에서 「오프라인 행사(방문 예약) 캠페인」을 켭니다
  2. 저장한 뒤 편집 화면에서 방문 날짜와 시간대별 정원을 등록합니다
  3. 방문객이 시간을 골라 예약하면 예약번호 8자리와 QR을 받습니다
  4. 행사 당일 현장 확인 화면에서 QR을 찍거나 번호를 손으로 넣어 입장 처리합니다

행사 캠페인은 결과물을 받지 않습니다. 사진이나 게시물 제출 화면이 뜨지 않고, 리워드도 0원으로 고정됩니다.

정원이 차면 대기로 잡힙니다. 앞사람이 취소하면 대기 1번이 자동으로 확정되고 알림이 갑니다.

본인 취소는 시작 2시간 전까지입니다. 그 뒤에는 운영진에게 문의하도록 안내가 뜹니다. 이미 입장한 예약은 운영진도 취소할 수 없습니다.

행사 운영 시 주의하실 점

초대 전용(비공개) 캠페인을 쓰실 때

  • 초대 번호는 캠페인마다 하나입니다. 초대받은 분들이 모두 같은 번호를 씁니다
  • 「번호 생성」을 누른 뒤 반드시 캠페인을 저장해야 링크가 동작합니다. 저장 전에는 링크 복사가 막히도록 해 뒀습니다
  • 번호를 새로 만들면 이미 보낸 링크는 전부 쓸 수 없게 됩니다
  • 초대 링크를 열면 모집 내용은 로그인 없이 보이지만, 날짜를 고르려면 로그인이 필요합니다. 초대 안내를 보내실 때 「먼저 로그인 또는 회원가입이 필요합니다」를 함께 적어 주시면 문의가 줄어듭니다

현장 확인 화면

  • 다른 행사의 예약번호는 받지 않습니다. 「다른 행사의 예약입니다」와 함께 어느 행사인지 알려 드리니 그 담당자에게 안내해 주세요
  • 예약 날짜가 오늘이 아니면 되묻습니다. 확인하시면 입장 처리됩니다
  • 대기 상태인 분은 입장할 수 없습니다
  • 인터넷이 끊기면 이 화면은 멈춥니다. 당일 아침에 명단을 인쇄해 두시고, 복구된 뒤 예약 현황에서 손으로 입장 처리해 주세요

여러 날짜를 나눠 캠페인을 만드셨다면 반드시 「같은 행사 묶음」으로 묶어 주세요. 안 묶으면 둘째 날 현장 확인 화면에 명단이 비어 보입니다.

예약 취소 기록을 화면에서 볼 수 있습니다

예약 현황에서 취소된 건에 누가 취소했는지(본인인지 운영진인지), 운영진이 취소했다면 누가·무슨 사유로 했는지가 표시됩니다. 명단 엑셀에도 같은 내용이 들어갑니다.

캠페인을 삭제하면 예약·취소 기록도 함께 사라집니다. 나중에 다툼이 생길 수 있는 행사라면 행사가 끝난 뒤 명단 엑셀을 내려받아 보관해 주세요.

관리자 화면 그 밖의 변경

  • 캠페인 편집에서 저장하지 않고 나가려 하면 확인창이 뜹니다. 「취소」·「저장하지 않고 나가기」·「저장」 중에서 고르실 수 있습니다
  • 「비공개 — 초대받은 사람만 신청」 체크칸이 아래로 내려가고, 켜면 바로 옆에 초대 번호가 나옵니다
  • 정산 목록과 엑셀에 영수증 금액·상한·상한 적용 여부가 표시됩니다
